# Murdilimax Browser v0.8.0 — Windows 10/11 x64 TEST BETA

Независимая тестовая версия Murdilimax. **Это не полный функциональный аналог Dolphin Anty.** Все платежи выполняются через прежний Stripe/Hatchable, никаких изменений цен, LIVE-ключей или дизайна сайта в этот выпуск не входит. macOS по-прежнему использует отдельную более раннюю v0.2.0.

## Новое: безопасные ограничения отпечатка

У каждого профиля в редакторе появился пункт «Предел экрана (fpgen)». Доступны `auto`, `1600x900`, `1920x1080`, `2560x1440`.

**Это максимальные размеры для выбора согласованного отпечатка Camoufox — не подмена разрешения монитора в точности до выбранных чисел.** Указанный предел используется при **первой генерации** отпечатка. Затем выбранный fpgen-отпечаток сохраняется в профиле и повторно используется при всех запусках.

После первого запуска изменение предела блокируется. Если нужна другая конфигурация — **дублируйте профиль**, но помните, что его cookies и сессии не копируются. Это защита от неожиданной смены идентичности сайта.

Пункт «◈ Отпечаток» в инструментах профилей показывает ограниченный локальный просмотр уже существующего отпечатка: ОС, предел экрана, выбранный размер, число потоков CPU и User-Agent. Он не генерирует новую идентичность, не отправляет данные в облако, не предлагает вручную менять WebGL, Canvas или User-Agent.

Остальные функции сохранены: локальный API v2, профили, прокси, cookies, стартовые вкладки, расширения, групповые закладки.

## Проверка на Windows

1. Остановите все браузерные профили и сделайте резервную копию `%USERPROFILE%\.murdilimax-browser`.
2. Скачайте с официального GitHub Release `Murdilimax-Browser-Windows-v0.8.0-Beta-Setup.exe`; проверьте SHA-256 из `SHA256SUMS.txt`.
3. Установите v0.8.0 (откат на [v0.7.0](https://github.com/virus53111/dogizen/releases/tag/v0.7.0-browser-windows-beta-20261101) остаётся доступным).
4. Создайте новый профиль, в настройках выберите максимум `1920x1080`. Нажмите «◈ Отпечаток»: должно быть сказано, что отпечаток пока не создан.
5. Запустите профиль, затем остановите. Откройте «◈ Отпечаток»: ожидается сохранённое описание. Изменить предел у этого профиля должно быть запрещено.
6. Запустите снова; проверьте, что cookies сохранились, браузер сообщил тот же screen и не сменил User-Agent.
7. Дублируйте профиль и выберите другой предел *до первого запуска*; новый профиль не должен получать сессии и cookies оригинала.
8. Проверьте прежние функции — прокси, расширения, API, закладки, остановку, восстановление cookies и проверку обновлений.

## Ограничения

Нельзя гарантировать отсутствие fingerprint-утечек, совместимость с любой антифрод-системой или копирование Canvas/WebGL в точности. Camoufox может отклонить слишком жёсткие условия для своей модели: при этом идентичность не должна записываться частично. Не изменяйте файлы `fingerprint-v1.json` вручную.

Установщик пока не имеет цифровой подписи издателя. Автоматическое тестирование Windows не заменяет полноценное тестирование на вашем компьютере. Нет облачной синхронизации, командных прав, сценарного конструктора, полной нативной настройки отпечатка и синхронизатора действий. Полный цикл оплаты и возвратов также требует отдельного тестирования без реальных пользовательских списаний.

При ошибке пришлите версию Windows, скриншот без личных данных и последовательность действий. Не присылайте cookies, пароли, токены или файлы профиля.
