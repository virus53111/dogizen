# Murdilimax Browser — локальный API профилей (developer beta)

**Не опубликовано в текущем релизе.** Разработка в ветке `feature/loopback-profile-api-20261101` / PR после прохождения CI. API доступен только владельцу компьютера и только при явном запуске. Оформление сайта и Stripe/Hatchable не затронуты.

## Безопасный запуск

В терминале, из каталога репозитория:

```bash
python -m pip install -r browser/requirements.txt
python browser/app.py --api-rotate-token
python browser/app.py --api-server
```

Первая команда генерации токена сохраняет случайный ключ доступа в **системном OS Keychain** и показывает его один раз. Сохраните его в менеджер секретов, никому не передавайте и **не записывайте в код или GitHub**. Повторная команда `--api-rotate-token` заменит токен; для вступления нового ключа в силу перезапустите запущенный API. Запуск API — отдельный процесс; обычный UI не открывает порт автоматически.

По умолчанию сервис слушает только `127.0.0.1:18765`, не `0.0.0.0`. Не настраивайте проброс порта через маршрутизатор, туннели или публичный reverse proxy. Допустим порт `--api-port 18766` (1024–65535). Проверяются Host, Origin и точный Bearer-токен; все операции над данными делаются только в локальной директории пользователя.

## Маршруты

| HTTP | Путь | Результат |
|---|---|---|
| GET | `/v1/health` | Статус и версия API |
| GET | `/v1/profiles` | ID, название, группа, теги, состояние, факт назначения прокси |
| POST | `/v1/profiles/{profile_id}/start` | Запросить старт; ответ 202 означает запуск, а не подтверждённое открытие браузера |
| POST | `/v1/profiles/{profile_id}/stop` | Отправить команду остановки |

**Не передаются** cookies, sessionStorage, localStorage, URL стартовой страницы, заметки, логины и пароли прокси, device tokens и сам API-токен. JSON-запросы с телом запрещены.

Пример вызова на Unix/Linux/macOS (без сохранения секрета в истории shell):

```bash
read -rsp "Local API token: " MURDILIMAX_TOKEN; echo
curl --fail --silent --show-error \
  -H "Authorization: Bearer ${MURDILIMAX_TOKEN}" \
  "http://127.0.0.1:18765/v1/profiles"
unset MURDILIMAX_TOKEN
```

Для запуска/остановки отправьте POST на путь с выбранным ID. API **не обходит тарифные ограничения**: перед стартом проверяется разрешённое количество профилей (а дочерний процесс проверяет его повторно). Для платных профилей необходимо серверное подтверждение Hatchable; при недоступности сервера запуск запрещён. API не производит платежи, не изменяет подписки, не отправляет данные в облако.

## Проверки до релиза

- [ ] `python -m unittest discover -s browser -p 'test_local_api.py' -v` проходит в Linux, Windows и macOS.
- [ ] Полный `Browser-only smoke tests` проходит на каждой ОС.
- [ ] Локальный сценарий: ключ из Keychain → список → запуск бесплатного профиля → остановка; неавторизованный запрос получает HTTP 401.
- [ ] Четвёртый профиль без платной лицензии получает HTTP 403 и не создаёт процесс.
- [ ] На физических Windows/macOS подтверждено, что порт доступен только с локального компьютера, нет CORS и ключ не записывается в логи.
- [ ] Описаны ограничения: локальный API не является облачным командным API, не гарантирует защиту от локального вредоносного ПО, физический QA не завершён.

До выполнения проверок не публиковать установщики и не рекламировать API как готовую функцию.
