# Murdilimax Browser — функциональный паритет с Dolphin Anty (рабочий чек-лист)

**Статус на 2026-11-01.** Ориентир: функции Dolphin Anty, **не копирование чужого дизайна, бренда или закрытого кода**. У существующего сайта murdilimax.com сохраняем оформление; сайт и десктопное приложение — разные продукты. **Stripe LIVE / Hatchable и настройки платежей не менять** в ветках разработки браузера.

## Подтверждённые возможности опубликованной v0.2.0 (beta)

- [x] Отдельные локальные каталоги Camoufox/Firefox для профилей, сохранение данных сайтов между запусками (проверено автоматикой).
- [x] Создание, изменение, копирование, удаление, поиск профилей; группы, теги, массовые операции и сортировка.
- [x] Привязка HTTP/HTTPS/SOCKS5-прокси, конфигурация и диагностика; проверка DNS/WebRTC/IPv6 **не завершена**.
- [x] Локальные Firefox XPI-расширения, резервное копирование, просмотр и восстановление собственных cookies.
- [x] RU/EN, Windows x64 и macOS Intel/Apple Silicon beta-сборки (CI; установка на физических компьютерах ещё обязательна).
- [x] Привязка аккаунта к устройству и серверная выдача лимита профилей через Hatchable (это **не** неподделываемый DRM).

## Код в проверке — пока НЕ считать опубликованными возможностями

- [ ] **PR #32:** импорт собственных cookies из ограниченного JSON / Playwright storage_state / Netscape TXT в остановленный Firefox-профиль, с резервной копией и проверкой сохранности после полного перезапуска. Сессионные и истёкшие cookies пока сознательно не поддерживаются.
- [ ] **PR #38:** атомарный импорт метаданных профилей с проверкой тарифного лимита до изменения файлов и отказ запуска платных профилей без серверной авторизации. Первые три профиля работают офлайн; нужен зелёный CI на всех целевых ОС.
- [ ] Убедиться, что все эти исправления перенесены в **одну** release-ветку, а не остались разрозненными, затем повторно прогнать все тесты.

## Отсутствует до паритета с Dolphin (план по приоритетам)

### P0 — базовая надёжность и коммерческая пригодность
- [ ] Реальная установка, первый запуск браузера, повторный запуск профиля, остановка/блокировки, cookies и прокси на обычных Windows и Mac.
- [ ] Полный набор отдельных проверок proxy egress, DNS, WebRTC, IPv6 без ложных утверждений о защищённости отпечатка.
- [ ] Безопасное обновление программы с сохранением профилей, резервной копией, откатом и подписанными / нотариализованными установщиками.
- [ ] Автоматическая проверка разрешений на сервере, корректность free/start/pro/business при изменении тарифа; тесты без реальных списаний.

### P1 — обязательные функции управления
- [ ] Расширенное редактирование совместимых настроек устройства и отпечатка с тестами согласованности, **без** заявления о гарантированном обходе обнаружения.
- [ ] Менеджер закладок, групповые расширения, статусы, фильтры и предустановленные стартовые страницы.
- [ ] Экспорт/перенос пользовательских профилей с явными правами и безопасными резервными копиями; чёткое разделение метаданных и секретов.
- [ ] Документированный локальный API для собственного рабочего процесса, права, аудит, ограничение доступа.
- [ ] Конструктор разрешённых автоматизированных сценариев с подтверждением пользователя и журналом запуска.

### P2 — масштабирование команд
- [ ] Команды, роли, права на конкретные профили и группы, приглашения, отзыв доступа.
- [ ] Синхронизация профилей между устройствами с шифрованием и разбором конфликтов.
- [ ] Синхронизатор действий между собственными профилями, устойчивое восстановление сессии.
- [ ] Удобная телеметрия работоспособности без отправки cookies, паролей или данных сайтов.

## Гейты перед новым релизом

1. CI: Python unit + реальный Camoufox (создание/закрытие/повторное открытие) на Windows, macOS Intel, macOS Apple Silicon, Linux; cookie import отдельно тестирует фактическую cookie в браузере.
2. QA на физических Windows/Mac: чистая установка, запуск/закрытие/перезапуск, профиль + прокси + cookies + XPI + импорт.
3. Данные: заведомо неверные и слишком большие файлы не меняют профили; при неудачной операции пользовательские данные и cookies восстанавливаются.
4. Тарифы: четвёртый профиль нельзя запустить без авторизации; первые три доступны без оплаты; состояние Stripe проверяется read-only — не проводить реальные платежи без отдельного разрешения.
5. UI: сравнение скриншотов существующего дизайна до/после; никакой переделки сайта и тарифного блока без отдельной задачи.
6. Только после этих проверок: release candidate, обновлённые загрузки и точные примечания об ограничениях беты.
