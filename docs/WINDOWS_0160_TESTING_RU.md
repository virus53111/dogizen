# Murdilimax Browser v0.16.0 — Windows 10/11 x64 Test Beta

Отдельная тестовая версия Murdilimax, без замены прежних установщиков и без изменений в Stripe, аккаунтах, Hatchable, тарифах, существующих профилях или дизайне сайта.

## Новое в Flow Studio

- Опциональный режим **«⇉ ПАРАЛЛЕЛЬНЫЕ ДЕЙСТВИЯ В ВЫБРАННЫХ ПРОФИЛЯХ»** для 1–10 собственных открытых профилей.
- Каждый отдельный блок сценария отправляется выбранным профилям параллельно через существующий безопасный локальный IPC. Следующий блок запускается только после подтверждения всех текущих действий.
- До запуска проверяются все активные сессии, права доступа и лицензии. Отказ в одном профиле останавливает следующие блоки и запрашивает отмену уже ожидающих действий.
- Существующие Flow продолжают работать в последовательном режиме без изменений. Режим сохраняется при редактировании и копировании сценария. В списке отображается «По очереди» или «⇉ Параллельно».
- Это **не** полное зеркалирование движений мыши или клавиатуры: параллельно исполняются только явно подтверждённые блоки Flow Studio. В других профилях уже выполненные действия не откатываются.

## Проверка на Windows

1. Полностью закройте приложение; сохраните резервную копию папки `%USERPROFILE%\.murdilimax-browser` в защищённом месте. Она может содержать действующие cookie/сессии.
2. Скачайте `Murdilimax-Browser-Windows-v0.16.0-Beta-Setup.exe` и `SHA256SUMS.txt` с GitHub Releases; проверьте SHA-256.
3. Установите в обычном режиме. Убедитесь, что локальные профили, cookies, закладки, прокси, расширения, тарифный статус и прежние Flow не изменились.
4. Создайте тестовый Flow с двумя собственными открытыми профилями. По умолчанию он работает в режиме **«По очереди»**.
5. Откройте редактор и включите «⇉ ПАРАЛЛЕЛЬНЫЕ ДЕЙСТВИЯ». Сохраните сценарий; в таблице должен отображаться новый режим.
6. Убедитесь, что URL → ожидание элемента → ввод обычного текста → клик → проверка текста выполняются параллельно в обоих профилях. При ошибке одного профиля следующие блоки не должны запускаться.
7. Убедитесь, что кнопка «Отменить» останавливает следующие шаги и ожидание текущих команд, но не обещает откат уже выполненных кликов.
8. Скопируйте Flow и проверьте сохранение режима. Измените режим у другого Flow, закройте с отменой несохранённых изменений — ранее сохранённый режим не должен поменяться.
9. Повторно запустите старые Flow v0.15.0; проверьте, что они остались последовательными и ранее сохранённые браузерные данные не повреждены.

## Автоматические критерии релиза

GitHub Actions выпускает этот prerelease только после полной Python unit suite, Windows Camoufox и Tk GUI acceptance, сохранения cookies при перезапуске, сборки PyInstaller EXE и selftest, Inno Setup.exe, установки в чистую директорию и selftest установленного EXE. Публикуются новый неизменяемый тег и файл SHA-256.

**Ограничения:** реальный домашний Windows 10/11 ПК пока не проверен; установщик не подписан сертификатом издателя. Не гарантируется сходство с Dolphin Anty по всем функциям или отсутствие обнаружения. Синхронизации сырых мыши/клавиатуры, облачных командных ролей и полной защиты WebRTC/DNS/IPv6 ещё нет.

**Откат:** прежняя [Windows v0.15.0](https://github.com/virus53111/dogizen/releases/tag/v0.15.0-browser-windows-beta-20261102) сохраняется. До отката сделайте дополнительную резервную копию собственного локального профиля.
