# Murdilimax Browser v0.6.0 — Windows 10/11 x64 TEST BETA

Этот установщик создан из публичных исходников Murdilimax, **не** из закрытого кода Dolphin Anty. Он не обеспечивает полный паритет: нет командной работы, облачной синхронизации и конструктора сценариев. **Дизайн murdilimax.com и Stripe LIVE не изменены.**

## Что нового в v0.6.0

- **Закладки:** отдельная вкладка «Закладки» → «＋ Закладка», название, HTTPS/HTTP ссылка и, при необходимости, точное название группы профилей. Пустая группа означает «для всех».
- При открытии профиля, у которого стартовый адрес **about:blank**, показывается **локальная стартовая страница** с разрешёнными закладками группы. Из неё можно перейти на сайт, не выходя из текущего изолированного Camoufox-профиля.
- Закладки сохраняются локально в `bookmarks.json`; это **не нативная панель закладок Firefox, не синхронизация в облако и не общие закладки команды**. Отключить страницу просто: укажите для профиля обычную стартовую HTTP/HTTPS страницу.
- **Проверка обновлений:** «О программе» → «Проверить обновления Windows». Только по явному нажатию отправляется запрос к официальному GitHub API; приложение предлагает открыть проверенную страницу релиза и **никогда не скачивает и не запускает EXE автоматически**.
- Сохранены возможности v0.5.0: быстрые профили, массовые назначения прокси, дополнительные стартовые вкладки, cookies, расширения, базовый локальный API.

## Установка и откат

1. Остановите все профили, закройте Murdilimax и сохраните отдельную резервную копию `%USERPROFILE%\.murdilimax-browser`.
2. Скачайте `Murdilimax-Browser-Windows-v0.6.0-Beta-Setup.exe` с GitHub Releases. Проверьте SHA-256 из `SHA256SUMS.txt`.
3. Установите в Windows 10/11 x64. Первый запуск браузера может отдельно загрузить Camoufox.
4. Для отката сохранён официальный v0.5.0: https://github.com/virus53111/dogizen/releases/tag/v0.5.0-browser-windows-beta-20261101

## Что протестировать на своём Windows

- [ ] Установка и запуск; 기존 данные профилей на месте. Проверить RU/EN.
- [ ] Создать закладку для всех профилей, затем для конкретной группы; запустить профиль `about:blank` с такой группой; должны показываться только подходящие ссылки.
- [ ] Открыть сайт по закладке, задать cookie, полностью остановить и снова открыть профиль. Cookie и идентичность должны сохраниться.
- [ ] Изменить/удалить закладку в интерфейсе, остановить и перезапустить профиль: изменения применились.
- [ ] Проверка обновлений не должна требовать лицензии, трогать платежи, скачивать программу или изменять профили. При отсутствии сети должна показывать предупреждение без зависания UI.
- [ ] Старые функции: три бесплатных профиля, лимит на четвёртый, прокси, импорт собственных cookies, стартовые вкладки, Firefox XPI, локальный API.
- [ ] Пустой профиль без закладок по-прежнему открывает `about:blank`. Если стартовая страница указана как `https://...`, менеджер закладок её не заменяет.

## Безопасность и ограничения

- Установщик пока **не подписан** цифровым сертификатом издателя; Windows SmartScreen может предупредить. Рекомендуется проверить SHA-256 и скачать только с официального GitHub релиза.
- Файл закладок содержит URL в незашифрованном виде, не добавляйте туда токены и конфиденциальные ссылки.
- Не отправляйте в баг-репортах cookies, пароли, платёжные реквизиты, токены API или файлы профилей.
- Windows CI подтверждает сборку, реальную работу Camoufox и тихую установку, но **не заменяет** физический QA на компьютере пользователя и не является гарантией обхода антифрода.
