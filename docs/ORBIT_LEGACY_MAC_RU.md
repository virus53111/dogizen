# Murdilimax Orbit Legacy — инструкция для Mac 2012–2014

## 1. Как определить macOS

В левом верхнем углу Mac нажми ** → Об этом Mac (About This Mac)**. Запиши версию macOS, модель и объём памяти.

Поддерживаемые экспериментальные цели: **Intel + macOS High Sierra 10.13 и выше**. Предпочтительно Catalina 10.15+, если твой Mac поддерживает её.

- MacBook Pro / Air 2012: как правило, официально максимум Catalina 10.15.
- MacBook Pro / Air 2013–2014: многие модели могут официально использовать Big Sur 11.
- Mac на High Sierra 10.13 или Mojave 10.14 нужно сначала обновить до Catalina или новее, если Apple поддерживает эту модель.

Apple: https://support.apple.com/en-us/102662

Прямая ссылка на High Sierra 10.13 / Mojave 10.14:

https://github.com/virus53111/dogizen/releases/download/v0.7.0-mac-high-sierra-adb-beta/Murdilimax-Orbit-Studio-ADB-macOS-10.13-Intel.dmg

Дважды кликни DMG, затем перетащи **Murdilimax Orbit Legacy.app → Applications (Программы)**. Открывай приложение из Applications.

Установщик **ad-hoc signed**, без Apple notarization. При предупреждении macOS открой Finder → правой кнопкой по приложению → Открыть и подтверди, если доверяешь источнику. Не отключай Gatekeeper и системную защиту целиком.

### Если macOS пишет «Apple cannot check it for malicious software»

По сообщению на MacBook Pro с обоями Catalina видно, что программа запускается **прямо из смонтированного образа DMG**. Это предупреждение **Gatekeeper**, поскольку бета-приложение не подписано сертификатом Apple Developer ID и не прошло нотариальную проверку Apple. Это само по себе не доказывает несовместимости с macOS.

1. В окне DMG перетащи **Murdilimax Orbit Legacy.app** на ярлык **Applications**.
2. Закрой образ, открой **Finder → Applications / Программы**, найди Murdilimax Orbit Legacy.
3. Нажми **Control + клик** (или правой кнопкой мыши) по программе → **Open / Открыть**.
4. Если Gatekeeper всё ещё блокирует приложение, зайди в ** → System Preferences → Security & Privacy → General** и выбери **Open Anyway / Всё равно открыть** после попытки запуска (если эта кнопка доступна).
5. Не отключай глобально Gatekeeper и не выполняй случайные команды `sudo` или `xattr` из интернета.

Документация Apple: https://support.apple.com/ru-ru/102445

**Внимание:** в отличие от нотариально заверенных приложений эта бета не проходила проверку Apple на известное вредоносное ПО. Разрешай запуск вручную лишь если доверяешь источнику и проверил файл.

Если ошибка повторится, пришли снимок нового окна и версию macOS из ** → About This Mac / Об этом Mac**. Если появляется ошибка **«app is damaged»** или **«requires a newer version of macOS»**, это уже другой случай и одного разрешения Gatekeeper недостаточно.

## 3. Работа браузеров

Кнопка **«Открыть отдельный браузер»** создаёт настоящее окно браузера через системный WebKit. Каждый профиль изолирован от другого с помощью отдельного временного хранилища cookies.

Ограничения:
- Сессии не сохраняются после закрытия.
- На старой Catalina WebKit зависит от системной версии браузерного движка и больше не получает все современные исправления безопасности.
- Это **не Camoufox / не антидетект**. Не использовать для чувствительных рабочих аккаунтов без актуальной защищённой системы.

## 4. Телефоны Android

Программа использует **ADB** (Android Debug Bridge). В Studio 0.7 добавлена проверенная установка официального ADB одной кнопкой. Сама Legacy-сборка не содержит большой Android SDK и не создаёт виртуальное устройство автоматически.

Для физических Android-телефонов: **в Studio 0.7 открой раздел «Android / ADB» и нажми «Установить ADB автоматически»**. После твоего согласия программа скачает официальный архив Google Platform-Tools 34.0.5 (~11 МБ), проверит SHA-256 и установит его в `~/Library/Application Support/Murdilimax Orbit Legacy/platform-tools`. Затем включи USB debugging на Android, подключи телефон и нажми «Найти Android». ADB не создаёт Android-эмулятор.

Для виртуального Android: необходима *старшая совместимая с твоей macOS версия Android SDK/Emulator* с установленным Android AVD. Современный Android Studio требует macOS 12 и более современный Intel/M1 CPU, поэтому его нельзя поставить на High Sierra/Catalina как обычную актуальную версию. Устаревший Android SDK следует использовать только в тестовой изолированной среде.

После подключения телефоны отображаются в **общей рабочей области Orbit Studio**: их можно двигать мышкой, менять размеры, раскладывать в сетку или ряд, клик отправляет касание через ADB. Изображение периодически обновляется — это не видеопоток 60 FPS.

Встроенные кнопки **Сетка** и **В ряд** располагают карточки подключённых телефонов в Studio.

## 5. Производительность старого Mac

- Желательно **8 ГБ ОЗУ и SSD**, для локальных Android AVD лучше **16 ГБ ОЗУ**.
- На 4 ГБ ОЗУ разумнее использовать один физический Android или один очень лёгкий эмулятор, а не несколько.
- Поддержка современных Android системных образов, Camoufox и аппаратное ускорение не гарантируются.

## 6. Аккаунты и коммерческий доступ

Кнопка **«Мой аккаунт»** открывает страницу авторизации через браузер. Пока аккаунт-сервис Murdilimax Orbit в Hatchable имеет видимость **Personal**, публичные пользователи не могут войти. В этой Legacy-бета версии лицензия настраивается как бесплатная локальная, **доступ к платным тарифам и проверка на одном устройстве ещё не интегрированы**. Платный тариф на этой версии НЕ ПРОДАВАТЬ.

## 7. Совместимость ещё не проверена на физическом Mac

DMG Studio 0.7 скомпилированы на CI под Intel с минимальными версиями macOS `10.13` и `10.15`; дополнительно проверен скачиваемый архив Google ADB 34.0.5 с SHA-256 и Intel-бинарник с минимальной macOS 10.13. На физическом Mac 2012–2014 нужен отдельный тест. Но сборка происходила на macOS 15. Проверка с настоящими Catalina и Big Sur ещё обязательна. Если Mac пишет «Программа не поддерживается», пришли: модель, macOS, ошибку и запускалась ли программа при открытии из Applications. Не отправляй пароли или токены.
