# MURDILIMAX: откуда приходит трафик и как добавить Яндекс / Bing

Проверено по репозиторию 14 ноября 2026 года. Этот документ — план измерения, а не отчёт о фактических посетителях.

## Что уже сделано технически

- Сайт опубликован на https://murdilimax.com/ через GitHub Pages и доступен поисковым роботам.
- Сборка автоматически создаёт HTML-страницы, `sitemap.xml`, canonical, hreflang и RSS `/feed.xml`, `/ru/feed.xml`.
- В `scripts/build-atlas.mjs` подключён GA4 `G-87PTY9JK62`, **только после согласия посетителя**. Отказы и некоторые блокировщики создают недоучёт.
- `public/robots.txt` не запрещает индексацию публичных статей. Доступность sitemap ещё не доказывает, что статья попала в выдачу.

## Как узнать, есть ли посетители из Яндекса прямо сейчас

1. Откройте [Google Analytics](https://analytics.google.com/) → нужный ресурс MURDILIMAX → Reports → Acquisition → Traffic acquisition.
2. Выберите последние 28 или 90 дней. Покажите измерение **Session source / medium** и найдите `yandex / organic`, `google / organic`, `bing / organic`. Сравните с `direct / (none)`, `referral` и `social`.
3. Для более точного учёта поисковых показов подключите собственность сайта в [Яндекс Вебмастере](https://webmaster.yandex.ru/): раздел статистики поисковых запросов / страницы в поиске покажет **клики из поиска Яндекса**, даже если посетитель отказался от GA4.
4. В [Google Search Console](https://search.google.com/search-console/) отдельно смотрите поисковые запросы и страницы Google. Это не отчёт по всему трафику и не включает Яндекс.
5. Не делайте вывод «в Яндексе нет трафика» по отсутствию `yandex / organic` в GA4: согласие и ограничения измерения могут скрыть часть визитов.

**Статус сейчас:** прямые отчёты GA4, GSC и Yandex Webmaster через подключённые инструменты не были доступны. Фактический объём трафика Яндекса **неизвестен**.

## Добавить сайт в Яндекс, Bing и остальные каналы

1. [Яндекс Вебмастер](https://webmaster.yandex.ru/): добавить `https://murdilimax.com/`, подтвердить владение, отправить `https://murdilimax.com/sitemap.xml`, проверить индексирование русскоязычных страниц. При необходимости вручную отправить важные новые URL на переобход. Поддержка Яндекса: https://yandex.com/support/webmaster/en/robot-workings/robot
2. [Bing Webmaster Tools](https://www.bing.com/webmasters/): подтвердить сайт (если доступен импорт из Google Search Console — проверить его условия), отправить ту же карту сайта, изучить отчёты индексирования.
3. При изменениях большого числа статей рассмотреть **IndexNow** для Bing и Яндекса — с корректно размещённым проверочным ключом. Не отправлять произвольные URL и не считать IndexNow гарантией индексации.
4. Если подключать **Яндекс Метрику**, обеспечить применимое уведомление/согласие и обновить политику конфиденциальности. Просто вставлять ещё один счётчик без проверки требований к приватности не следует.
5. Контент можно продвигать в тематических сообществах, Telegram, YouTube, Pinterest, Reddit и Дзене, но с **оригинальными полезными анонсами**, релевантностью сообществу и соблюдением правил площадки. Не массово публиковать одинаковые ссылки и не покупать ботов.
6. Проверяйте внешние источники через корректные UTM-метки, например `?utm_source=telegram&utm_medium=social&utm_campaign=evergreen_faq`; для органических поисковых результатов UTM обычно не нужны.

## Какие KPI отслеживать

| Показатель | Где искать | Как использовать |
|---|---|---|
| Organic sessions по источнику | GA4 | Видеть фактические переходы согласившихся посетителей из Google, Yandex, Bing |
| Показы, клики, CTR, средняя позиция | Google Search Console / Яндекс Вебмастер | Выбирать запросы, где уже есть поисковый спрос |
| Доля проиндексированных статей | Вебмастера | Искать технические ошибки, а не писать новые страницы вслепую |
| Landing page + engagement | GA4 | Понять, какие статьи действительно помогают посетителям |
| Referral/social sessions по кампании | GA4, UTM | Сравнить эффект публикаций вне поиска |

Приоритет: сначала исправить индексацию и улучшить существующие страницы с показами, затем расширять тематические кластеры оригинальными текстами. Не обещать «большой трафик» по факту публикации: нужны наблюдаемые показы, позиции, конкуренция и время.
