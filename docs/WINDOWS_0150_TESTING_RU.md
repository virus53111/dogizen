# Murdilimax Browser v0.15.0 — Windows 10/11 x64 Test Beta

Отдельная тестовая версия оригинального Murdilimax Browser на Camoufox, с новым блоком **ПРОВЕРИТЬ ТЕКСТ** для Flow Studio. Эта версия не заменяет предыдущие установщики, не отключает Stripe/Hatchable и не изменяет тарифы или оформление сайта.

## Что нового
- Новый безопасно ограниченный блок **ПРОВЕРИТЬ ТЕКСТ**: CSS-селектор (1–300 символов), фрагмент обычного текста (1–120 символов), ожидание видимости текста до 15 секунд.
- Реальное выполнение в текущем браузерном профиле через Playwright locator. После клика/заполнения можно проверить появление нужной надписи. При отсутствии элемента или текста сценарий завершается ошибкой, следующие блоки не запускаются.
- Сам текст страницы не возвращается в редактор и не отправляется через IPC: внутри профиля выполняется только проверка, результат — boolean «успех / ошибка».
- Сохранены все прежние блоки и функции Windows v0.14.0: изолированные профили, cookies, прокси, создание и копирование Flow, выбор целевых профилей, защита несохранённых изменений.

## Ручная проверка на Windows
1. При закрытой программе сделайте приватную резервную копию `%USERPROFILE%\.murdilimax-browser`; она может содержать активные сессии.
2. Скачайте `Murdilimax-Browser-Windows-v0.15.0-Beta-Setup.exe` и `SHA256SUMS.txt` только с официального GitHub Releases; сверьте SHA-256.
3. Установите программу. Убедитесь, что прежние профили, cookies, закладки, прокси, расширения и сценарии сохранились.
4. Создайте собственную тестовую страницу с кнопкой, после клика показывающей «Готово». Создайте Flow: URL → КЛИК → ПРОВЕРИТЬ ТЕКСТ на CSS-селекторе сообщения с ожидаемым словом «Готово». Убедитесь в успешном выполнении.
5. Измените ожидаемый текст на несуществующий: Flow должен остановиться и **не выполнить следующие шаги**. Подтвердите соблюдение тайм-аута и отмены.
6. Проверьте отказ для пустого текста, текста длиннее 120 символов, селекторов полей паролей, времени за пределами 1–15 секунд и дополнительных полей JSON.
7. Проверьте старые сохранённые Flow из v0.14.0, копирование, изменение целевых профилей и восстановление браузерных данных после закрытия/перезапуска.

## Автоматические проверки
Гейт релиза: полная Python unit suite, Camoufox и визуальные GUI smoke-тесты на Windows, сохранение cookies и профилей, PyInstaller EXE и selftest, Inno Setup.exe, установка в отдельную директорию и selftest уже установленного EXE. SHA-256 публикуется вместе с новым тегом только после успеха всех этапов.

**Ограничения:** Windows CI не заменяет тест на физическом Windows 10/11 ПК, издательская подпись отсутствует, SmartScreen может показывать предупреждение. Полного паритета Dolphin Anty нет: не реализованы облачная командная синхронизация, роли, полноценные условия/ветвления и синхронизатор окон. Не вводите пароли, токены, платёжные сведения или другие секреты в блоки Flow.
