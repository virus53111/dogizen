# Murdilimax Browser v0.4.0 — Windows 10/11 x64 TEST BETA

**Тестовая Windows-сборка, не подтверждение паритета с Dolphin Anty.** Она не заменяет платёжный сайт и не изменяет Stripe. Mac-дистрибутив v0.2.0 остаётся доступен отдельно; новая Mac-сборка не публикуется, пока не пройдёт проверки.

## Новое в v0.4.0
- До **7 дополнительных стартовых вкладок** на профиль (всего до 8 вместе с главной страницей). Вкладки открываются в том же изолированном Camoufox-профиле.
- Выберите **один остановленный профиль** на вкладке «Профили» → нажмите «Стартовые вкладки» на панели под списком → впишите по одному HTTP/HTTPS-адресу на строку → «Сохранить».
- Дополнительные стартовые страницы сохраняются при редактировании, копировании и импорте/экспорте настроек. Неверные адреса не должны изменять существующий профиль.
- URL могут содержать конфиденциальные параметры в строке запроса; не передавайте файлы экспорта настроек посторонним.

## Как проверить новую функцию на Windows
- [ ] Создать профиль, указать 2 разные стартовые вкладки, нажать «Запустить»: открываются 3 страницы вместе с основной.
- [ ] Полностью остановить и снова запустить: те же страницы открываются, cookies и собственные данные профиля не теряются.
- [ ] Дублировать профиль и проверить, что список стартовых вкладок скопировался, но сессии сайтов не скопированы.
- [ ] Ввести `file:///etc/passwd`, `javascript:...` или более семи вкладок — программа должна отказать без частично сохранённых настроек.

## Как установить
1. Сохраните резервную копию каталога `%USERPROFILE%\\.murdilimax-browser` (остановите все профили до копирования).
2. Скачайте `Murdilimax-Browser-Windows-v0.4.0-Beta-Setup.exe` из GitHub Release, проверьте SHA256 по `SHA256SUMS.txt`.
3. Установите обычным способом в Windows 10 или 11 x64. Старые личные данные браузера находятся отдельно от установщика.
4. При первом запуске профиля программа отдельно скачает движок Camoufox — нужен интернет.
5. Держите оригинальный установщик v0.2.0 для отката: автоматический откат **не реализован**.

## Windows Local API (не включается автоматически)
Найдите установленный `Murdilimax Browser.exe`. Через PowerShell из папки установки:

```powershell
& '.\\Murdilimax Browser.exe' --api-rotate-token
& '.\\Murdilimax Browser.exe' --api-server
```

В версии для Windows ключ API откроется в отдельном окне (так как GUI-приложение собрано без консоли). API слушает только `127.0.0.1:18765`. Не публикуйте ключ в отчёте об ошибке. Остановить API можно завершением отдельно запущенного процесса; управление сервисом через GUI пока отсутствует.

## Ограничения
- Сборка предварительная и пока не сертифицирована Windows SmartScreen. Запуск движка проверяется на автоматической Windows-машине; полноценное тестирование на пользовательском компьютере обязательно.
- Нет облачной синхронизации, командных прав, синхронизации действий и полного редактора fingerprint. Нельзя гарантировать единый результат на всех антифрод-системах.
- Импортируются только собственные неповреждённые persistent cookies. Session-only cookies пока не поддерживаются.
- Не предоставляйте в баг-репортах cookies, токены, пароли или дампы профилей.

## Отчёт об ошибке
Напишите версию Windows, что нажали, ожидаемый и фактический результат, текст сообщения и (если безопасно) скриншот. Описывайте без паролей, платёжных реквизитов и реальных cookies.

Состояние сервера лицензий и Stripe не меняется этим выпуском. Продажи не тестируются реальными списаниями.
