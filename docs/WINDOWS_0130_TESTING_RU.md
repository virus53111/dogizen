# Murdilimax Browser v0.13.0 — Windows 10/11 x64 TEST BETA

Это новая тестовая сборка Murdilimax на основе Camoufox. Она опубликована после успешного полного Windows CI; установщик предыдущей v0.12.0 остаётся доступен в истории GitHub Releases. Полный паритет Dolphin Anty пока не достигнут. Stripe, тарифы, дизайн сайта, данные аккаунта и Mac v0.2.0 не изменяются.

## Что нового

- В собственном неоновом **✦ Flow Studio** появился блок **«ОЖИДАТЬ ЭЛЕМЕНТ»**: ожидает видимость выбранного CSS-селектора 1–15 секунд. Если нужный элемент не появился, блок возвращает ошибку, и последующие шаги не выполняются.
- Все пять прежних видов блоков (URL, пауза, CSS-клик, ввод обычного текста, прокрутка) остаются без изменений. Существующие сохранённые Flow совместимы.
- Редактор предупреждает о несохранённых изменениях при закрытии окна; прокрутка длинного списка карточек работает колёсиком мыши.
- Программа по-прежнему проверяет локальный сеансовый токен, PID запущенного браузера и тарифный допуск перед действиями и хранит только короткое подтверждение «успех/ошибка». Данные страниц и cookies не передаются в облако через Flow Studio.

## Как проверить на Windows

1. Перед обновлением сохраните локальную резервную копию `%USERPROFILE%\.murdilimax-browser` в безопасном месте при полностью закрытой программе.
2. Скачайте только официальный `Murdilimax-Browser-Windows-v0.13.0-Beta-Setup.exe` из GitHub Releases, сверьте его SHA-256 с `SHA256SUMS.txt`.
3. Установите Windows Setup.exe; убедитесь, что прежние профили, cookies, прокси, шаблоны, закладки, расширения и сохранённые сценарии не пропали.
4. Запустите собственный тестовый профиль Camoufox и создайте Flow: URL → ОЖИДАТЬ ЭЛЕМЕНТ (например, `#search`, до 8 секунд) → заполнить поле → клик → прокрутка.
5. Убедитесь, что ожидание успешно проходит на тестовой странице и выдаёт отказ, если указанный селектор отсутствует или тайм-аут истёк. Следующие действия после ошибки не запускаются.
6. Создайте несколько блоков, измените их порядок и название, закройте редактор, выбрав «Нет» в предупреждении — несохранённые изменения должны остаться в открытом окне. При подтверждении закрытия сохраняется старая версия Flow.
7. Проверьте прокрутку карточек колёсиком и сохранение отредактированного Flow. Старые сценарии и cookies должны остаться прежними.
8. Проверьте невалидные URL, пустые селекторы, лишние атрибуты и ожидание за пределами 1–15 секунд — они должны отклоняться.

## Автоматические релизные ограничения

GitHub Actions выпускает новый prerelease **только после успеха**: полной Python unit suite, Windows native Camoufox и Tk GUI-теста, сохранения cookies при перезапуске, сборки PyInstaller EXE, его selftest, генерации Inno Setup.exe, тихой установки на чистую директорию и selftest уже установленного EXE. Автоматизированный Windows runner не заменяет ручное тестирование на физическом ПК.

**Ограничения:** Windows-установщик пока не подписан сертификатом издателя; SmartScreen может предупреждать. Облачная синхронизация и команды, синхронизатор мыши, циклы и ветвления Flow Studio, полная проверка WebRTC/DNS/IPv6 и гарантии неотслеживаемости отсутствуют.

**Откат:** прежняя проверенная бета [Windows v0.12.0](https://github.com/virus53111/dogizen/releases/tag/v0.12.0-browser-windows-beta-20261102). Перед откатом сохраните собственные данные профилей. Не вводите секреты, пароли, платёжные сведения или API-токены в текстовые блоки Flow.
