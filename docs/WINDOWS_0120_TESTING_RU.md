# Murdilimax Browser v0.12.0 — Windows 10/11 x64 Beta

## Собственный Flow Studio Murdilimax

Новая вкладка **✦ Flow Studio** — самостоятельный визуальный конструктор в фирменном неоновом оформлении Murdilimax. Это **не копия дизайна Dolphin Anty**. Цель развития — сопоставимые полезные функции при собственной графике, сценарной логике и пользовательском опыте.

Что работает в первой версии:
1. Выделите от 1 до 10 **уже работающих** профилей во вкладке «Профили».
2. Откройте «✦ Flow Studio», нажмите «✚ Создать Flow».
3. Добавьте до **12 блоков** из собственной неоновой палитры и измените их порядок стрелками вверх/вниз: **URL** (новая вкладка HTTP/S), **Пауза** (1–30 секунд), **CSS-клик**, **Обычный текст в поле**, **Прокрутка** (-1500…1500 пикселей). Можно редактировать и удалять карточки.
4. Назовите Flow и нажмите «СОХРАНИТЬ FLOW». Он сохраняется в локальном `visual_flows.json`.
5. Вернитесь к списку Flow и нажмите «▶ Выполнить Flow». После явного подтверждения блоки выполняются **последовательно** через Camoufox, с ожиданием подтверждения каждого действия, проверкой активной сессии браузера и лицензии. По ошибке последующие блоки не выполняются.
6. «■ Отменить» прекращает последующие действия; текущая уже выполняющаяся команда может закончиться. Прошедшие клики и ввод нельзя откатить автоматически.
7. При удалении Flow профили, их файлы и cookies не затрагиваются.

Для CSS-блоков используется **последняя вкладка соответствующего профиля**. В разных вкладках или на сайтах с динамической версткой пользователь должен корректно подобрать селекторы. Все действия выполняются локально в собственном Camoufox-процессе пользователя. Процесс отправляет статус **успех/ошибка без URL, текста, cookies и содержимого страницы**. Произвольные JavaScript, shell, Python, файловые адреса и сценарии удалённого управления не поддерживаются.

**Конфиденциальность:** файл `visual_flows.json` может содержать обычные URL и вводимый текст! **Не сохраняйте пароли, API-токены, платёжную информацию, секреты и ссылки с приватными query-параметрами.** Поля с селекторами, содержащими `password`, запрещены, но это не полноценный менеджер секретов. Команды временно хранятся в приватной директории только до обработки; результаты не сохраняют текст.

## Приёмочные проверки

- [ ] Сделайте копию `%USERPROFILE%\.murdilimax-browser`, затем установите официальный `Murdilimax-Browser-Windows-v0.12.0-Beta-Setup.exe` и сравните SHA-256 с `SHA256SUMS.txt`.
- [ ] Программа запускается; предыдущие профили, шаблоны, API, закладки, cookies и старые сценарии доступны.
- [ ] «✦ Flow Studio» имеет **собственный** Murdilimax-стиль: тёмный фон, неоновые карточки, значки, связи блоков и оригинальные надписи.
- [ ] Создайте Flow с блоками URL → заполнение простого поля → CSS-клик → прокрутка → пауза. Переставьте шаги, сохраните и снова откройте. Порядок и значения сохраняются.
- [ ] Выполните Flow на своём тестовом сайте. Команды фактически вызываются в Camoufox; результат зависит от DOM сайта. Куки других профилей не меняются.
- [ ] Неверный селектор вызывает ошибку и предотвращает последующие действия. Отмена не уничтожает профиль и не закрывает Camoufox.
- [ ] Попробуйте `file:`, `javascript:`, пароль в URL, блок с паролем, больше 12 шагов — запрещены.
- [ ] При неактивном профиле, недействительном платном разрешении или неожиданном перезапуске профиля команда не выполняется в чужой сессии.
- [ ] Старые функции v0.11.0 работают, обновление версии и доступ к лицензии не нарушены.

Полная Windows сборка проходит отдельные автоматические тесты: Python unit suites на Windows/macOS/Linux, настоящая Windows Tk отрисовка, реальный Camoufox по локальному HTTP-тестовому сайту, сборка EXE и проверка установки Setup.exe. Это не равнозначно полноценному ручному GUI-тестированию на пользовательской системе.

**Откат:** предыдущая версия [v0.11.0](https://github.com/virus53111/dogizen/releases/tag/v0.11.0-browser-windows-beta-20261102). Подпись Windows издателя пока отсутствует.

## Ещё не готово

Flow Studio пока не поддерживает ветвления, циклы, условные проверки, визуальное обучение на движениях пользователя, синхронизацию кликов между окнами, запись скриншотов, секреты в keyring, командные роли или облачную синхронизацию. macOS остаётся на v0.2.0. Полный коммерческий паритет Dolphin Anty **не достигнут**. Stripe LIVE, дизайн сайта, цены и личные кабинеты этим выпуском не изменяются.
