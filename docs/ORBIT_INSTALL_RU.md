# Murdilimax Orbit — состояние и инструкция по установке

## Windows
Скачайте Murdilimax-Orbit-Windows-Setup.exe со страницы https://murdilimax.com/download.html и запустите установщик. При первом запуске можно выбрать «Без аккаунта» — пока публичная авторизация не включена.

## macOS
Выберите DMG для Apple Silicon или Intel, откройте DMG и перетащите приложение в Applications. Приложение пока не заверено нотариально Apple. При предупреждении используйте стандартное контекстное меню Finder → Открыть, если доверяете источнику. Не отключайте защиту macOS глобально.

## Android
ADB и scrcpy входят в установщик. Для создания новых виртуальных телефонов требуется Android SDK с Command-line Tools и Emulator, аппаратная виртуализация и интернет. Установите Android Studio с официального сайта https://developer.android.com/studio, откройте вкладку Android и нажмите «Создать Android-телефон». После подтверждения Orbit может загрузить системный образ Android, размер которого составляет несколько гигабайт. Экраны можно открывать в scrcpy или в экспериментальной общей студии Android. Общая студия делает снимки экрана примерно раз в секунду; плавное видео — через scrcpy.

## Браузеры
Camoufox включён в сборку как Python-модуль, но сам исполняемый движок может скачиваться при первом запуске из интернета. Выберите «Браузерные профили», создайте профиль и нажмите «Запустить». Cookies и история разных профилей хранятся в отдельных папках. Можно указать прокси HTTP, HTTPS или SOCKS5.

## Аккаунты
Email-вход с одноразовым кодом и подтверждение устройства реализованы на сервисе Hatchable Murdilimax Orbit. Публичный вход недоступен, пока владелец не изменит Visibility на Public. Google-вход также требует подтверждённого собственного домена и настройки OAuth владельцем. Пока можно использовать «Без аккаунта», без синхронизации.

## Что ещё не готово для коммерческого запуска
- Реальные тесты на физических Mac и Windows после установки.
- Нотариальное заверение macOS через Apple Developer ID и подпись Windows-приложения.
- Полностью автоматическая установка Android SDK без Android Studio.
- Надёжный видеопоток для десятков устройств в едином рабочем пространстве; пока используется ADB-предпросмотр.
- Публичная авторизация Google и email, биллинг, тарифные лимиты, облачная синхронизация и резервные копии.
- Политика конфиденциальности/GDPR, лицензии компонентов и независимый аудит безопасности.
- Camoufox не гарантирует нераспознаваемость профиля. Обычный Android Emulator не является Android-антидетектом.
