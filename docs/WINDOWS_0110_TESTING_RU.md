# Murdilimax Browser v0.11.0 — Windows 10/11 x64 TEST BETA

Независимый Murdilimax Browser, **не полный аналог Dolphin Anty**. В v0.11.0 добавлена локальная команда открытия нового URL в **уже запущенных** профилях Camoufox. Стиль сайта, Stripe LIVE, тарифы, данные аккаунта и Mac v0.2.0 не меняются.

## Что нового

- На вкладке «Профили» выберите от 1 до 20 **открытых** профилей, нажмите **«↗ Открыть URL»**, введите обычную HTTP(S)-ссылку и подтвердите действие. Новая вкладка открывается отдельно внутри соответствующего профиля; сессии, cookies и отпечатки остаются изолированными.
- На вкладке «Сценарии» появился тип **`navigate`**. Создайте сценарий из списка профилей, затем при выполнении введите ссылку. **Сам URL не сохраняется** в файле `scenarios.json`: в нём остаются только локальные ID профилей и тип действия.
- Навигация работает **только локально** и только в работающем Camoufox. Нет удалённого порта управления, произвольных скриптов JavaScript, синхронизатора нажатий или расширения доступа к сайтам.
- Перед записью команд приложение проверяет все выбранные профили, их PID и действующую лицензию. При ошибке предварительной проверки команды никому не отправляются; при неожиданной ошибке во время записи возможны ранее поставленные запросы — это показывается как частичная операция.
- Команда привязана к случайному секрету **текущей сессии конкретного браузера**. Старая команда не будет воспроизведена после рестарта, даже при повторном использовании PID операционной системой.
- У каждого профиля приватная очередь до 20 команд; запись атомарная. В запросах допустимы только HTTP/HTTPS без встроенных логинов/паролей, пробелов и управляющих символов. Никаких значений cookies, токенов или содержимого страниц не записывается в очередь.

**Ограничение:** ответ «Отправлено» означает, что команда поставлена в локальную очередь, а не что сайт гарантированно открылся или авторизован. Каждый новый URL открывается как отдельная вкладка. Ссылки с приватными параметрами временно хранятся в локальном файле до обработки; избегайте токенов в адресах.

## Как установить

1. Остановите браузерные профили и закройте программу, сделайте копию `%USERPROFILE%\.murdilimax-browser`.
2. Скачайте `Murdilimax-Browser-Windows-v0.11.0-Beta-Setup.exe` с официального GitHub Release и сравните хэш с `SHA256SUMS.txt`.
3. Установите программу; для отката остаётся предыдущая [v0.10.0](https://github.com/virus53111/dogizen/releases/tag/v0.10.0-browser-windows-beta-20261102). Установщик пока не подписан.

## Проверить на Windows

- [ ] Запустить один профиль и нажать «↗ Открыть URL» с обычным тестовым сайтом. Убедиться, что новая вкладка появилась именно в выбранном профиле.
- [ ] Повторить с двумя запущенными профилями; убедиться, что cookies, аккаунты и отпечатки не смешались.
- [ ] Создать сценарий `navigate`, выбрать профили и выполнить, введя HTTP(S)-адрес только при запуске. Перезапустить приложение: сам адрес не должен быть сохранён в `scenarios.json`.
- [ ] Попробовать `javascript:`, `file:`, `data:`, URL со встроенным паролем и слишком длинную ссылку — команда должна быть отвергнута.
- [ ] Проверить, что остановленный профиль нельзя заставить навигировать и что лицензия проверяется без возможности обойти оплачиваемое количество профилей.
- [ ] Отправить URL, закрыть профиль до выполнения, открыть заново. Старый запрос не должен открыться в новой сессии.
- [ ] Проверить сохранность bookmarks, templates, extensions, proxy, cookies backup, screen bounds и всех ручных сценариев.
- [ ] Проверить, что после установки не изменились сайт, цены, Stripe и страницы оплаты.

## Ограничения и безопасность

Эта бета не содержит полного визуального конструктора сценариев, записи движений мыши, синхронизатора кликов, облачной синхронизации, командных прав или обширного редактора fingerprint. Навигация в профилях **не является обходом антифрода**. Автоматические тесты Windows CI не заменяют проверку на физическом компьютере. Не отправляйте в отчётах cookies, пароли, токены, платежи или файлы профилей.
