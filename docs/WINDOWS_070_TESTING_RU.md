# Murdilimax Browser v0.7.0 — Windows 10/11 x64 TEST BETA

Это новая тестовая версия Murdilimax с более функциональным **локальным API**. Не является полным аналогом Dolphin Anty и не поддерживает облачную синхронизацию или команды. Платёжная система Stripe LIVE, дизайн murdilimax.com и Mac-сборки не изменяются.

## Новое в v0.7.0
- **Локальный API v2** для своих профилей: список и детали, запуск/остановка, создание пустых профилей, дублирование метаданных, безопасное редактирование остановленного профиля, получение названий/ID прокси.
- **Управление API из приложения**: «О программе» → «▶ Локальный API», «■ Остановить API», «↻ Новый ключ API». Ключ сохраняется в системном хранилище и показывается при создании только один раз.
- Запросы принимаются исключительно с `127.0.0.1:18765`, требуют ключа. Из ответов исключаются пароли, cookies, URL профилей, адреса прокси и другие секреты; неизвестные поля в запросах отклоняются.
- При создании более трёх профилей требуется действующая **серверная** лицензия и разрешённый тарифный лимит; HTTP-параметр с произвольным лимитом не принимается. Запуск платного профиля также проверяет разрешение повторно.
- Сохранены возможности v0.6.0: закладки, стартовые вкладки, cookies, прокси, расширения, быстрые профили и проверка обновлений.

API документирован в [руководстве](https://github.com/virus53111/dogizen/blob/main/docs/LOCAL_PROFILE_API_V2_RU.md). Это **не** API удалённого управления, не Chromium DevTools Protocol и не запуск чужих скриптов. **Не открывайте и не пробрасывайте порт наружу.**

## Установка
1. Полностью закройте приложение и браузерные профили. Сделайте копию каталога `%USERPROFILE%\.murdilimax-browser` перед установкой.
2. Скачайте `Murdilimax-Browser-Windows-v0.7.0-Beta-Setup.exe` только из официального GitHub Release и сверьте SHA-256 с `SHA256SUMS.txt`.
3. Установите программу. Camoufox скачивается при первом запуске профиля при наличии интернета.
4. Для отката доступна [v0.6.0](https://github.com/virus53111/dogizen/releases/tag/v0.6.0-browser-windows-beta-20261101).

## План пользовательского теста
- [ ] Обычная установка Windows 10/11 x64, открытие окна, запуск/закрытие профиля, сохранность cookies после перезапуска.
- [ ] В «О программе» запустить локальный API. Сохранить показанный ключ в менеджере паролей, **не отправлять в отчёт об ошибке**.
- [ ] Подключиться PowerShell к `http://127.0.0.1:18765/v1/health` и `/v1/profiles` со своим ключом. Проверить создание одного бесплатного профиля.
- [ ] У третьего бесплатного профиля всё работает; создание четвёртого без активной платной лицензии возвращает отказ и не создаёт профиль.
- [ ] Изменение остановленного профиля и копирование метаданных корректны; работающий профиль нельзя редактировать, cookies не копируются между профилями.
- [ ] Остановить API и проверить, что порт недоступен. Обновить ключ: старый токен не подходит.
- [ ] Проверить старые функции: назначение прокси, закладки, расширения, cookies, стартовые вкладки, локальные резервные копии.

## Ограничения и безопасность
- Это **beta**, в том числе нет удостоверенной цифровой подписи Windows, автоматического отката и полной проверки на физическом компьютере пользователя.
- Локальный API не содержит облачных функций, командных ролей, редактора fingerprint, конструкторов сценариев или синхронизатора действий. Не выдавайте beta за подтверждённый коммерческий паритет с Dolphin Anty.
- Проверки автоматической установки и реального Camoufox выполняются в GitHub Actions перед публикацией; они не подтверждают отсутствие всех сетевых утечек и совместимость с любой версией Windows.
- Не передавайте разработчикам пароли, профили, сессии, токены, файлы cookies или платёжные данные. Вместо этого отправляйте скриншот без личных сведений, описание действий и сообщение ошибки.

**Все платежи и подписки сохраняют существующую инфраструктуру; никаких реальных списаний для CI не производится.**
