# Murdilimax Browser v0.14.0 — Windows 10/11 x64 Test Beta

Это отдельный тестовый выпуск Murdilimax Browser с улучшенным оригинальным Flow Studio. Он **не изменяет** Stripe, текущие тарифы, дизайн сайта, работу аккаунтов, Mac v0.2.0 или опубликованные предыдущие EXE. Полного функционального паритета с Dolphin Anty пока нет.

## Что добавлено

- **Изменить профили** внутри редактора Flow: выберите от 1 до 10 существующих локальных профилей, сохранив шаги сценария. У диалога есть «Применить» и «Отмена». Изменение не запускает браузеры и не переносит данные или cookies.
- **Копировать Flow** в списке сценариев: создаётся отдельный Flow с новым ID и уникальным именем («копия», «копия 2» и т. д.). Копируются только определения шагов и ссылки на профили, но не их файлы, сессии, cookies, прокси-пароли или лицензии. Ограничение — 40 сценариев.
- Все предыдущие блоки, включая **ОЖИДАТЬ ЭЛЕМЕНТ**, и защита несохранённых изменений остались.
- Запуск существующих Flow по-прежнему требует локальных активных профилей, подтверждения пользователя и проверки полномочий. Обновление не добавляет запуск произвольного JavaScript или shell.

## Проверка на Windows

1. Закройте приложение и сохраните приватную резервную копию `%USERPROFILE%\.murdilimax-browser`; она может содержать действующие сессии.
2. Получите только официальный `Murdilimax-Browser-Windows-v0.14.0-Beta-Setup.exe` и файл `SHA256SUMS.txt` из GitHub Releases; сравните SHA-256.
3. После установки проверьте существующие браузерные профили, cookies, закладки, прокси, локальные API, расширения, сценарии и Flow.
4. Откройте ранее сохранённый Flow, нажмите **Изменить профили**, добавьте второй профиль. Нажмите **Отмена** — исходные цели должны остаться прежними. Повторите и нажмите **Применить** → **Сохранить Flow** — должны сохраниться новые цели, а шаги — не измениться.
5. Копируйте Flow несколько раз, убедитесь, что у каждого независимый ID и имя, а редактирование и удаление копии не изменяют оригинал и его browser state.
6. Проверьте недопустимые варианты: 0 или больше 10 профилей, удалённые профили, 40 Flow, закрытие редактора с несохранёнными изменениями.
7. Запустите только на собственных открытых тестовых профилях сценарий URL → ожидание CSS-элемента → ввод обычного текста → клик. Действия должны реально выполняться в Camoufox.
8. Запустите старые сценарии v0.13.0 и убедитесь, что сохранение cookies и прежняя прокси-конфигурация работают.

## Release gates

Автоматизированный релиз разрешён только после Python unit/regression suite, настоящего Windows Camoufox и Tk GUI smoke, реального теста профилей и cookies, PyInstaller EXE selftest, создания Inno Setup.exe, тихой установки в чистую директорию и selftest уже установленного EXE. Публикация имеет новый тег и SHA-256, не заменяя старые файлы.

**Ограничения:** Windows CI не заменяет проверку на физическом Windows 10/11 ПК. Установщик пока не подписан сертификатом, а SmartScreen может предупреждать. В Flow Studio нет полноценной синхронизации мыши между окнами, ветвлений, циклов и облачного рабочего пространства. Гарантии полной неотслеживаемости нет.

**Откат:** предыдущий [Windows v0.13.0](https://github.com/virus53111/dogizen/releases/tag/v0.13.0-browser-windows-beta-20261102) доступен независимо. Сохраните отдельную резервную копию собственных локальных профилей перед установкой или откатом.
