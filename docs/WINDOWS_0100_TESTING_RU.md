# Murdilimax Browser v0.10.0 — Windows 10/11 x64 TEST BETA

Это независимая локальная программа Murdilimax, **не полный аналог Dolphin Anty**. В v0.10.0 добавлены первые ручные сценарии управления собственными профилями. Не изменяются дизайн murdilimax.com, Stripe LIVE, действующие подписки или Mac v0.2.0.

## Сценарии: первый локальный функционал автоматизации

На вкладке «Профили» выделите 1–20 профилей и нажмите **«✦ Сценарий»**. Введите название, затем тип: `start` (последовательный запуск), `stop` (команда остановки) либо `session` (последовательный запуск, ожидание 5–300 секунд и команда остановки). Сценарий появится на новой вкладке **«Сценарии»**. Для выполнения требуется явное подтверждение пользователя.

**Что обеспечивает безопасность:**
- Проверка существования всех выбранных профилей и тарифного допуска **перед первыми действиями**. Каждая команда запуска повторно проверяет лицензию, а процесс Camoufox делает свою дополнительную проверку.
- Отказ при запуске, техническом обслуживании или уже открытом браузере в сценариях запуска. Не допускается произвольная загрузка скриптов/JavaScript или доступ к чужим аккаунтам.
- При ошибке операции прекращаются, но **ранее успешно запущенные браузеры не закрываются автоматически**, чтобы не потерять пользовательские данные.
- **Отмена** останавливает следующие команды или ожидание. Если браузер уже открылся — он остаётся открыт.
- Во временном сеансе остановка отправляется только в процесс, который действительно запустил данный сценарий. Если вы перезапустили профиль сами, новый процесс не будет закрыт сценарием.
- Файл `scenarios.json` хранит только идентификаторы собственных профилей, название и тип операции. Нет паролей, URL сайтов, cookies, токенов API и готовых отпечатков.

**Важно:** подтверждение запуска означает *отправку команды*, а не готовность сайта, авторизацию или завершение загрузки. Для сеансов с таймером 5 секунд может не хватить на первый запуск Camoufox. При пропавшем процессе или изменившемся PID сценарий пропустит остановку ради сохранности браузера. Это не фоновый планировщик, не визуальный конструктор произвольных скриптов и не синхронизатор действий между окнами.

Все функции v0.9.0 сохранены: локальные шаблоны профилей, закладки, API v2, cookies и их резервные копии, расширения, прокси, стартовые вкладки, настройки отпечатка.

## Установка и безопасный откат

1. Остановите все профили и Murdilimax, сделайте резервную копию `%USERPROFILE%\.murdilimax-browser`.
2. Скачайте `Murdilimax-Browser-Windows-v0.10.0-Beta-Setup.exe` только с официального GitHub Release. Сверьте SHA-256 с `SHA256SUMS.txt`.
3. Установите программу. Для отката доступна предыдущая [v0.9.0](https://github.com/virus53111/dogizen/releases/tag/v0.9.0-browser-windows-beta-20261102).

## Проверить на Windows

- [ ] Программа запускается; старые профили, прокси, cookies и шаблоны на месте.
- [ ] Выделить два бесплатных профиля, создать сценарий `start`, подтвердить выполнение: браузеры запускаются отдельно, cookies не перемешиваются.
- [ ] Создать сценарий `stop` для уже работающих профилей, подтвердить; проверить корректное завершение и сохранность cookies.
- [ ] Сценарий `session` с ожиданием 30 секунд запускает собственный профиль, ожидает и отправляет команду остановки. Для первого запуска Camoufox дайте больше времени.
- [ ] Во время ожидания нажать «■ Отменить»: уже работающие браузеры **не должны** быть неожиданно закрыты.
- [ ] Пробовать сценарий с профилем, который в данный момент уже запускается, либо с профилем вне тарифа: никаких частичных действий до прохождения проверки.
- [ ] Самостоятельно закрыть и заново открыть профиль пока сценарий ожидает: таймер не должен останавливать новый процесс с другим PID.
- [ ] Перезапустить программу, проверить сохранённые сценарии, удаление сценария без удаления профилей.
- [ ] Повторить тесты расширений, закладок, прокси, импорта cookies и проверки лицензии.

## Ограничения и незавершённые функции

Установщик Windows пока без цифровой подписи. Тесты GitHub Actions на Windows не заменяют полноценную проверку на компьютере пользователя. Для полноценного паритета с Dolphin Anty всё ещё нужны командные права, облачная синхронизация, полноценный конструктор сценариев, action synchronizer, расширенные настройки отпечатков и полный аудит оплаты и возвратов. Ни одна из этих функций не заявляется завершённой.

В баг-репортах не отправляйте cookies, пароли, токены API, профили или платёжную информацию.
