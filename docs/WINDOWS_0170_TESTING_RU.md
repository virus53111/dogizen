# Murdilimax Browser v0.17.0 — Windows 10/11 x64 Test Beta

Новая Windows-версия Murdilimax с пользовательской проверкой целостности скачанного установщика и всеми функциями v0.16.0. **Этот выпуск не меняет LIVE Stripe, сервер аккаунтов, тарифы, данные браузерных профилей, macOS и опубликованные прежние установщики.**

## Что нового

- **Проверить скачанный Setup.exe (SHA-256)**: кнопка во вкладке информации выбирает локальный Windows-установщик и сверяет его имя, размер и SHA-256 с официальным GitHub Releases и `SHA256SUMS.txt`. Загрузка файла в интернет, автоматический запуск и установка **не производятся**. Несовпадение, подменённая ссылка или повреждённый файл блокируют подтверждение.
- Весь предыдущий функционал сохранён: Camoufox, самостоятельные профили, cookie backup/import/restore, закладки, прокси, расширения, Local API, Flow Studio и добровольный параллельный запуск шагов в нескольких профилях.
- Добавлен внутренний документ `docs/PRODUCTION_SECURITY_GATE_RU.md` с результатами отдельного аудита Hatchable и доказанными ограничениями тестовых правил доступа. **Новые правила не применялись на рабочем сервере.**

## Как принять на настоящем Windows 10/11

1. Закройте Murdilimax, сохраните закрытую резервную копию `%USERPROFILE%\.murdilimax-browser`. В профилях могут быть секретные cookies и действующие браузерные сессии.
2. Скачайте официальные `Murdilimax-Browser-Windows-v0.17.0-Beta-Setup.exe` и `SHA256SUMS.txt` с GitHub Releases. Сверьте SHA-256 установщика внешней утилитой `certutil -hashfile <путь> SHA256` или PowerShell `Get-FileHash`.
3. Установите Setup.exe; проверьте прежние профили, прокси, cookie persistence, закладки, расширения, Local API, Flow и параллельные сценарии.
4. В разделе информации выберите **Проверить скачанный Setup.exe (SHA-256)** и укажите официальный v0.17.0 Setup.exe. Программа должна показать совпадение SHA-256 и номер версии, ничего не устанавливая.
5. Переименуйте сторонний EXE, измените байт в **тестовой копии** Setup.exe или выберите повреждённый файл — проверка должна отклонить его без запуска. Проверка только читает файл и официальные метаданные, но не заменяет цифровую подпись издателя.
6. Запустите старые последовательные Flow, новые параллельные Flow с двумя собственными профилями, тестовые cookies и восстановление. Проверьте откат на предыдущую [v0.16.0](https://github.com/virus53111/dogizen/releases/tag/v0.16.0-browser-windows-beta-20261102) при закрытом приложении.

## Строгие релизные проверки

GitHub Actions выпускает **отдельный неизменяемый тег** только после полной Python unit suite, тестов пользовательской проверки SHA-256, настоящего Windows Camoufox и Tk GUI, браузерных профилей и cookies, PyInstaller EXE `--selftest`, сборки Inno Setup.exe, установки в чистую директорию и повторного `--selftest` установленной программы. Контрольная сумма публикуется вместе с установщиком.

## Что пока остаётся до стабильного 1.0

- Реальная аппаратная проверка на ПК Windows 10 и 11; Authenticode-подпись ещё отсутствует и предупреждение SmartScreen возможно.
- Незавершён P0-аудит разграничения аккаунтов/Stripe: тестовая копия Hatchable выявила, что жёсткое ограничение записей ломает законные webhook/checkout; рабочие права **не менялись**. Требуются TEST-подписанные события, проверенная обработка очереди и строгий two-user QA перед изменением production.
- Не реализованы облачное командное хранилище профилей и живое зеркалирование сырых движений мыши/клавиатуры; нет гарантии обхода всех систем антифрода.

**Предыдущие Setup.exe доступны независимо.** Не удаляйте папки профилей при установке, обновлении или откате.
