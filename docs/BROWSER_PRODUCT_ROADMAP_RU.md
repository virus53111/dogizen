# Murdilimax Browser — план отказа от Android

## Цель
Самостоятельная программа для Windows 10/11 и macOS (Intel/Apple Silicon): управление изолированными браузерными профилями. Вдохновляемся набором задач Dolphin Anty, НЕ копируем дизайн, бренд или код и не обещаем 100% обхода антифрод-систем.

## Выполнено в feature/orbit-browser-only-2026-10-31
1. Сохранена независимая резервная ветка `backup/orbit-android-before-browser-only-2026-10-31`.
2. Новый независимый код `browser/`: локальные профили, метаданные, прокси, отдельные процессы Camoufox, графическая панель, первичные тесты.
3. Android-компоненты не используются новой программой и отсутствуют в целевой дорожной карте.

## P0 — сделать продукт проверяемым (в работе)
- Зафиксировать совместимые версии Python, Camoufox, Playwright и проверить установку из чистого окружения.
- Исправить обнаруженные ошибки с помощью CI, затем вручную протестировать профиль на Windows/macOS.
- Пиннинг стабильного отпечатка на профиль с корректной миграцией при обновлении движка; тесты WebRTC/DNS/Canvas/WebGL/UA.
- Тест HTTP и SOCKS5 до целевого сайта; проверить выходной IP, геолокацию и возможные утечки.
- Удобный менеджер proxies, в т.ч. редактирование, массовое применение, безопасное хранение ключей.
- Импорт/экспорт cookies, журнал ошибок и восстановление профилей с согласия пользователя.
- Сборка инсталляторов EXE/DMG, QA на настоящих компьютерах, подписывание дистрибутивов.
- Публичный сайт должен рекламировать только существующие функции; Android убрать из навигации.

## P1 — функциональный паритет
- Менеджер расширений Firefox и закладок, шаблоны, быстрые фильтры, статусы, массовые операции.
- Проверка скорости/здоровья прокси, ротация и интеграция с разрешёнными провайдерами.
- Сценарии автоматизации и локальный API только с аутентификацией и привязкой к localhost.
- Работа профилей в командах без доступа к чужим cookies и секретам.

## P2 — коммерческий продукт
- Авторизация и восстановление доступа, облачные резервные копии и синхронизация (шифрование на клиенте).
- Подписки только после платёжного webhook и серверной проверки прав.
- Роли участников, аудит действий, согласие на передачу профиля.
- Автообновление с криптографической проверкой подписей и откатом при ошибках.

## Совместимость
- Windows 10/11 x64 — основной таргет.
- macOS Apple Silicon и Intel — проверить современные поддерживаемые версии.
- macOS Catalina 10.15 — ОБЯЗАТЕЛЬНО отдельная проверка: актуальный Camoufox и PyInstaller могут требовать более новую ОС. Нативный WebKit не равен полноценному Camoufox. Нельзя выдавать загружаемое приложение за совместимое, пока QA не подтвердит.

## Разделение источников
- `dogizen/main`: публичный сайт + старая Orbit (до слияния нового релиза).
- `browser/`: новый продукт только для браузеров.
- Hatchable `murdilimax-orbit`: старый API аккаунтов с Android-квотами; НЕ использовать для коммерческого browser-only биллинга, пока не обновлены схемы и row-level policies.
- Все старые Android/legacy инсталляторы сохранить в GitHub Releases для архива, но убрать из главной навигации.
