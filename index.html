ЕСТЬ ВОПРОСЫ?

Мы отвечаем
без сложностей.

Ничего не скрываем: это развивающийся продукт, и у него есть чёткие этапы до коммерческого релиза.

Можно ли уже скачать программу? +

Тестовые сборки Windows и macOS доступны через GitHub Actions. Это пока не коммерческий релиз: полноценный запуск Camoufox и установку на реальных устройствах ещё проверяем.

У меня будет один аккаунт на сайте и в программе? +

Это целевая архитектура. Подтверждение email-кодом и passkey уже предусмотрено; Google-вход заработает после настройки домена и OAuth. Настольная программа подключается одноразовым кодом.

В чём отличие от Dolphin Anty? +

Murdilimax — независимая разработка со своим брендом и движком Camoufox (Firefox). Мы ориентируемся на профессиональный опыт управления профилями, но не обещаем идентичную функциональность или гарантированный обход обнаружения.

Когда можно будет оплатить подписку? +

После подключения и проверки Stripe, тарифных ограничений, восстановления доступа и документов для покупателей. Сейчас оплата не принимается.

Будет версия для Android и старого Mac? +

Для macOS Catalina нужна отдельная проверка совместимости браузерного движка. Мобильный менеджер доступен как устанавливаемое веб-приложение для Android и iPhone, но полноценный мобильный антидетект пока не создан. Как установить на телефон →
