WORKSPACE FEATURES

Профили без хаоса

В новой ветке приложения реализована основа менеджера. Ниже — фактические функции исходников, а не обещание коммерческого релиза.

◈Отдельные профили

Создание, изменение, дублирование и запуск браузеров в самостоятельных процессах с разными каталогами данных.

◎Cookies и хранилище

Постоянные каталоги Camoufox для cookies, localStorage и кэша на конкретном компьютере.

⌁Прокси

Конфигурации HTTP, HTTPS, SOCKS5; пароль через системное хранилище ключей. Проверка TCP — базовая.

≡Порядок в работе

Группы, теги, заметки, поиск, массовый запуск, остановка и резервное копирование настроек.

⎔Camoufox

Основа на Firefox с генерацией браузерных параметров. Постоянство отпечатка между запусками ещё дорабатывается.

⌂Локальные данные

Нет облачной синхронизации в начальной версии. Профили остаются на компьютере пользователя.

QUESTIONS

Частые вопросы

Это тот же Dolphin Anty?

Нет. Это самостоятельная разработка с собственным интерфейсом и кодом. Часть функций Dolphin Anty используется как ориентир для дорожной карты.

Где Android и виртуальные телефоны?

Они исключены из нового продукта. Предыдущие версии сохранены в архиве GitHub и не входят в новую линейку Murdilimax Browser.

Работает ли на macOS Catalina 10.15?

Совместимость актуального движка Camoufox с Catalina ещё не подтверждена. Не будем предлагать отдельный «антидетект» для Catalina, пока не пройдут реальные тесты.

Можно ли уже использовать как коммерческий антидетект?

Пока нет. Это ранняя локальная бета. До публичного запуска необходимы тесты движка, поведения отпечатков, сетевых настроек и защищённости.
