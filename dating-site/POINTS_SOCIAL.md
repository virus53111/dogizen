# Public points and profile gifts
One source of truth: the existing MP reward ledger. Additive migration 035 adds account-level opt-in (default false for all, including existing members). Public API view excludes non-opted-in, incognito, banned, unapproved and archived/unowned listings. Only public profile ID, display name, avatar and points are exposed by leaderboard; one row per account, rank by current nonnegative balance, top 20, deterministic ties. Public visibility can be switched in wallet and does not change ability to receive gifts. Cards and profile show badges only for public points, personal balance visible to logged-in owner on homepage. Profile gift uses exact listing UUID, existing server-side transactional ledger, idempotency key and explicit confirmation. No test gifts on live accounts; integration tests use local disposable PostgreSQL. No cash, payment, subscription or VIP activation.
