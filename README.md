# MURDILIMAX

Кинокаталог с адаптивным интерфейсом, поиском, категориями и избранным.

## Публикация

Статический сайт: включите GitHub Pages для ветки main, корень /.
Домен: murdilimax.com (файл CNAME включён). Настройте DNS на GitHub Pages у регистратора домена.

Контент демонстрационный. Для воспроизведения подключайте только разрешённые видеоматериалы. Постеры загружаются из TMDB CDN; проверьте условия использования перед коммерческим запуском.
