01 / LOCAL DATA

Локальные профили

Программа сохраняет настройки профилей, группы, теги и параметры прокси на вашем компьютере. Cookies, cache и localStorage браузерных сессий хранятся в независимых каталогах профилей. Пароли прокси предполагается сохранять в системном хранилище ключей Windows или macOS.

02 / ACCOUNT SYSTEM

Аккаунты и лицензии

Сервис учётных записей может обрабатывать электронную почту, хеши токенов, идентификатор установки и IP для проверки авторизации и ограничения использования лицензии. Google OAuth ещё не включён. Публичный доступ к регистрации на этапе тестирования ограничен.

03 / NETWORK

Сетевые подключения

Браузер обращается к сайтам, которые вы открываете. При использовании прокси соединение направляется через выбранный сервер. При первой установке движок Camoufox и дополнительные компоненты могут загружаться из внешних источников. Сам сайт размещён на GitHub Pages; инфраструктура хостинга может фиксировать технические данные соединения.

04 / DATA CONTROL

Экспорт и удаление

Экспорт настроек локальной беты содержит метаданные профилей, но не экспортирует cookies и пароли. При удалении профиля данные перемещаются в локальную папку trash и могут быть удалены пользователем окончательно.
