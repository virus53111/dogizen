ТЕХНОЛОГИИ 0.7

Под капотом — реальный код.

Экспериментальный движок восстановления данных. Ниже — реализованные функции, для которых ещё необходимы проверки на реальных дисках.

▣

NTFS / exFAT

Поиск удалённых записей и восстановление файлов по уцелевшим метаданным в поддерживаемых ситуациях.

⌕

Потерянные разделы

Поиск сохранившихся NTFS/exFAT томов и резервных таблиц GPT в образах накопителей.

⟁

RAID 0 / 1 / 5 / 6 / 10

Шесть схем RAID 5, RAID 6 с фиксированными P/Q, RAID 10 near-2 и осмотр Linux MD 1.2. Только из образов дисков; точные параметры задаются вручную.

✥

File Carving

Поиск JPG, PNG, PDF и ZIP по сигнатурам даже при потере информации об имени файла.

⚿

Crypto Backup

Локальный поиск видимых файлов кошельков и резервных копий по названиям; без передачи секретов на сайт.

⛨

Read-only

Исходные данные открываются для чтения. Результаты восстановления записываются отдельно.

▤

Образы HDD/USB

Создание побитовых копий с картой нечитаемых участков и продолжением прерванной операции.

◇

SHA-256 и проверка

Хеширование и базовая структурная проверка восстановленных файлов. Не гарантирует целостность.

☷

Локальные отчёты

Фиксация ошибок, файлов и результатов проверки на твоём компьютере.

▧

Предпросмотр фотографий

Просматривай отдельные найденные фотографии до сохранения. Файл остаётся на исходном носителе.

⤴

Удалённые папки exFAT

Поиск части вложенных файлов в удалённых каталогах, когда их кластеры не были заняты снова.

✓

CRC проверка архивов

Проверка ZIP и контейнеров Office с ограничениями на размер. Повреждения отмечаются, а не скрываются.
