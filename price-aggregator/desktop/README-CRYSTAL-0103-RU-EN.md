# MURDILIMAX Recovery Crystal 0.10.3 — RU/EN

## Русский
Исправление шрифта интерфейса: приложение выбирает установленный системный шрифт с поддержкой кириллицы, включая Ё/ё. Выпуск прекращается при ошибке проверки реальных глифов в Windows. Шрифты не загружаются с сайтов.

Для Windows 10/11 x64 скачайте установщик MURDILIMAX-Recovery-Setup-0.10.3.exe. Python отдельно не требуется. Устанавливайте программу только на исправный носитель, а восстановленные файлы записывайте на другой диск.

Ограничения: экспериментальная программа; не испытана на настоящем повреждённом RAID/HDD и не гарантирует восстановление всех файлов. Для неисправных накопителей обращайтесь к специалистам.

## English
0.10.3 uses a verified system font with full Cyrillic glyph coverage. The Windows build is blocked if the required glyphs are unavailable. No fonts are downloaded and no telemetry is sent.
Download the Windows 10/11 x64 EXE installer; Python is bundled. The data recovery engine is unchanged. Not field-validated on failing physical disks. Always image valuable sources and recover to separate storage.
