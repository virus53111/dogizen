# MURDILIMAX Recovery 0.2 / Альфа

**Внимание:** рабочая лабораторная альфа-версия, НЕ доказано превосходство над R-Studio, DMDE или TestDisk.

## Русский

### Возможности

- Анализ **побитовых, несжатых образов** дисков `.img`, `.dd`, `.bin`, `.raw` без записи на источник.
- Обнаружение томов **NTFS и exFAT**: разделы MBR/GPT и прямые образы разделов; ограниченный поиск потерянных загрузочных секторов в стандартных смещениях.
- NTFS: чтение записей `$MFT`, проверка update-sequence fixups, поиск удалённых записей и восстановление **резидентных файлов** и **нефрагментированных либо фрагментированных потоков** из data-runs. Восстанавливает пути папок из родительских записей `$MFT`, в том числе если папка была удалена, но её запись сохранилась.
- NTFS: чтение `$Bitmap` (если доступен), проверка, были ли кластеры переиспользованы. При явном переиспользовании восстановление блокируется.
- exFAT: чтение удалённых наборов записей файлов в каталогах, обработка непрерывных цепочек и существующих цепочек FAT, проверка bitmap (в пределах поддерживаемых вариантов).
- Отдельный режим **file carving**: поиск JPEG, PNG, PDF и ZIP по сигнатурам на образах (из предыдущей версии, эвристический).
- Выборочное восстановление файлов в другую папку с сохранением имеющейся структуры каталогов и расчётом SHA-256.
- Фильтр **Crypto backups** по именам резервных копий кошельков; содержимое seed-фраз и приватных ключей не просматривает, никуда не передаёт.
- Работа без интернета, аккаунта, телеметрии и оплаты.

### Ограничения, о которых нужно знать

- **Не сканирует напрямую физические HDD/USB/SSD и не исправляет исходные диски**. Для работы сначала создайте образ через ddrescue/другой специализированный инструмент.
- NTFS: не реализованы `$ATTRIBUTE_LIST`, сжатые/зашифрованные потоки, разбор USN Journal, реконструкция повреждённого `$MFT`, потоков из нескольких attribute extents, RAID, APFS, ReFS, BitLocker.
- exFAT: если FAT-цепочка удалённого файла была обнулена, восстановление неизвестной фрагментации пока невозможно. Большие/фрагментированные битовые карты размещения могут быть непроверяемыми.
- Файлы, отмеченные **reallocated**, автоматически не восстанавливаются: это может быть содержимое другого файла. Для **unknown** требуется отдельное подтверждение.
- Даже успешная запись файла на новый диск не гарантирует целостность исходного содержимого. Невозможно обещать восстановление данных после TRIM и перезаписи.
- Проверено на **7 синтетических образах/сценариях**, созданных тестовым скриптом. Полных независимых испытаний на реальных устройствах не было.

### Как запустить Windows 10/11

1. Установите **Python 3.11+** с [python.org](https://www.python.org/downloads/). Нужен стандартный модуль Tkinter.
2. Распакуйте архив (не запускайте из ZIP).
3. Дважды щёлкните `START-MURDILIMAX-WINDOWS.bat` или выполните в терминале `py murdilimax_recovery_v02.py`.
4. Выберите **Deleted files: NTFS / exFAT image**, нажмите Browse и укажите путь к образу диска `.img` / `.dd`.
5. Нажмите **SCAN SOURCE**, выберите найденные файлы и сохраните их **на другой физический диск**.
6. Если NTFS/exFAT метаданные недоступны, можно попробовать режим **Signature scan** (имена файлов будут потеряны).

Если диск трещит, исчезает или выдаёт ошибки чтения — **не сканируйте его повторно**. Сначала создайте образ с картой ошибок при помощи ddrescue или обратитесь в профессиональную лабораторию. Не используйте опцию восстановления поверх исходного диска. Используйте только устройства, которыми владеете или на которые получили разрешение владельца.

### Автотесты

`py -m unittest -v test_engine.py`

### Как собрать Windows .exe самостоятельно

`py -m pip install pyinstaller`

`py -m PyInstaller --onefile --windowed --name MURDILIMAX-Recovery --paths . murdilimax_recovery_v02.py`

Готовый `.exe` будет в папке `dist/`. Он должен быть протестирован на чистой Windows и подписан перед публичным распространением.

## English

**Research alpha, not a validated R-Studio/DMDE replacement.** Read-only parsing of NTFS/exFAT uncompressed disk images, detection of deleted metadata, reconstruction of NTFS data runs and folder paths, allocation bitmap reuse detection, selective export to a separate location, optional raw signature carving. Folder mode can filter wallet backup filenames. No secret extraction, cloud uploads, payments or telemetry. Run `python murdilimax_recovery_v02.py`; execute `python -m unittest -v test_engine.py` to verify the supplied synthetic fixtures. Recover to another physical disk. No encrypted volume, advanced RAID, damaged physical media access, or guaranteed recovery of overwritten content.
