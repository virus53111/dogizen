WHAT IS IN THE PACKAGE?

Проверяем настоящий браузер, а не демонстрацию

Что уже закодировано

  • Десктопный менеджер профилей с локальной базой настроек
  • Отдельные процессы и папки данных
  • HTTP/HTTPS/SOCKS5 прокси
  • Поиск, группы, теги и массовые операции
  • Проверки исходников и пакетов в CI

Что не объявляем готовым

  • Постоянный отпечаток между запусками
  • Проверенный обход обнаружения / неуязвимость к банам
  • Синхронизация cookies через облако
  • Сертификация на Catalina
  • Коммерческий биллинг и командный API
Для установки тестовой сборки из GitHub Actions может потребоваться вход в GitHub. После успешного QA выпустим обычные прямые ссылки на EXE/DMG в GitHub Releases и подпишем установщики.
