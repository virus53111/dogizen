Пошаговая инструкция на русском ↗
⚠️ Mac пишет «Apple cannot check it for malicious software»?

Эта бета-версия пока не нотариально заверена Apple. Такое предупреждение не означает, что Mac слишком старый. Если ты скачал приложение из нашего GitHub и доверяешь ему, можно разрешить запуск только этого приложения через настройки macOS.

  1. Открой DMG и перетащи Murdilimax Orbit Legacy.app на папку Applications слева. Не запускай приложение прямо из DMG.
  2. Открой Finder → Applications, найди Murdilimax Orbit Legacy, нажми Control + клик → Open / Открыть.
  3. Если снова будет предупреждение:  → System Preferences → Security & Privacy → General → Open Anyway. При появлении запроса подтверди открытие.
  4. Не выключай защиту macOS полностью. Если вместо этого появляется «damaged», «requires newer macOS» или окно исчезает после запуска — это другая ошибка, пришли её скриншот.

Установка с неподтверждённым сертификатом несёт риск. Для нормального коммерческого распространения потребуется сертификат Apple Developer ID и нотариальное заверение. Официальная инструкция Apple ↗
