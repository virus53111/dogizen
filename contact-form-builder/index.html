What fields should a contact form include?

For most contact requests, three fields are enough: a name, a reply-to email address and a message. If the visitor needs to choose a department or topic, a short dropdown can route requests into clear categories.

Use human labels such as 'What can we help with?' instead of a vague 'Description'. Explain what happens after submission, and avoid asking for a phone number or address unless it is necessary for the request.

How to build a contact form

Murdilimax Forms includes a no-code visual editor and supported question types such as email, short text, paragraph, dropdown, checkbox and file upload.

  1. Sign in with an email code and create a new form called 'Contact us'.
  2. Add a name field, an email field and a longer message field.
  3. Add an optional topic dropdown only if it will help you respond.
  4. Preview your contact form on desktop and mobile, then publish it.
  5. Share the public link or use the available embed option on your website.

Share a contact form link or embed the form

A public form link is useful for social profiles, event pages and email signatures. Respondents can use the link without creating an account.

For an existing website, Murdilimax Forms supports iframe embedding. A popup form option is also available with a script snippet, making it possible to collect a quick question without navigating away from a page. Check your site's privacy policy before collecting personal information.

Keep incoming messages organized

Answers appear in the private responses dashboard and can be exported as CSV. If you have an existing workflow, HTTPS webhook events can help pass new responses to another system; native integrations should be checked separately before relying on them.

File attachments currently support small PDF, JPG and PNG files up to 2 MB each. Consider whether you actually need attachments; simpler contact forms are usually easier to complete on mobile.

Frequently asked questions

Do visitors need to log in?

No. People can submit answers through a published public form link.

Can I put the form on my own site?

Yes. The service supports embedding published forms via iframe and offers a popup embed option.

Where are messages stored?

Submitted responses are available to the form owner in the private workspace, with CSV export.
